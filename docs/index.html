怎麼算出來的

每天收盤後,先用證交所公開資料抓全上市股票的成交量與價格做流動性初篩,再對候選股票計算近 90 個交易日的均線、RSI、量能、相對大盤強弱等指標,合成一個 0–100 分的分數後由高到低排序。
